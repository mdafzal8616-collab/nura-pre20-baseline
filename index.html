Forgot your passphrase?

There is no way to recover a lost Vault passphrase — it is never stored anywhere, even by this app. The only option is to permanently erase this Vault and start a new one. Everything currently inside it will be lost.

Clear Vault

This permanently deletes your passphrase and every entry on this device. This cannot be undone.

Encryption

Entries are encrypted with AES-GCM (256-bit) using the browser's built-in Web Crypto API. The key is derived from your passphrase with PBKDF2 (150,000 iterations) and is never stored — only held in memory while unlocked, and only on this device. This has not been independently security-audited.
